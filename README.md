# Paul BLANC - Portfolio

Portfolio personnel de Paul Blanc, Consultant Data freelance basé à Lyon.

**[paulblanc.fr](https://paulblanc.fr/)**

## Features

- **i18n** : Francais / Anglais avec changement de langue via drapeaux
- **Themes** : 5 themes DaisyUI (light, dark, nord, sunset, synthwave)
- **Responsive** : mobile-first avec menu hamburger
- **Carrousel projets** : auto-scroll avec pause au hover, navigation manuelle
- **SEO** : meta description, Open Graph, Twitter Card
- **Formulaire de contact** : Web3Forms + SweetAlert2
- **Images WebP** : compression 98% par rapport aux originaux
- **Lazy loading** : images chargees a la demande sous le fold

## Stack technique

| Categorie | Technologies |
|-----------|-------------|
| Frontend | React 19, TypeScript, Tailwind CSS, DaisyUI |
| Build | Vite 7, pnpm |
| i18n | i18next, react-i18next, i18next-browser-languagedetector |
| UI | lucide-react, Embla Carousel |
| Contact | Web3Forms, SweetAlert2 |
| Hebergement | Hostinger |

## Installation

```bash
git clone https://github.com/PaulBLC/Portfolio.git
cd Portfolio
pnpm install
pnpm dev
```

Le site est accessible sur `http://localhost:5173/`

## Build de production

```bash
pnpm build
```

Le dossier `dist/` contient le site pret a deployer.
